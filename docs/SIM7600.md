# SIM7600 gateway

SIM7600 support depends on the exact USB composition, modem firmware, carrier,
SIM subscription, and regional network. Data registration does not prove that
SMS, voice, VoLTE, or USB PCM will work.

## Hardware gate

1. Use a stable power supply and preferably a powered USB hub.
2. Confirm the USB device does not repeatedly disconnect in `dmesg`.
3. Install `deploy/99-onsim.rules`.
4. Confirm `/dev/onsim-at`, `/dev/onsim-control`, and `/dev/onsim-audio`.
5. Test SIM readiness, registration, SMS, calls, DTMF, and PCM independently.

```sh
lsusb
dmesg --ctime | tail -100
scripts/probe-modem.sh
```

The supplied udev rules cover the tested `1e0e:9011` composition. Different
firmware may expose different interfaces; inspect descriptors rather than
guessing port numbers.

## Configure

Use the SIM7600 compose overlay:

```sh
export ONSIM_GATEWAY_MODE=sim7600
podman compose -f compose.yaml -f compose.sim7600.yaml up -d --build
```

For Quadlet, set:

```dotenv
ONSIM_GATEWAY_MODE=sim7600
ONSIM_MODEM_MODE=auto
ONSIM_AT_PORT=/dev/onsim-at
ONSIM_CONTROL_PORT=/dev/onsim-control
ONSIM_AUDIO_PORT=/dev/onsim-audio
```

## Required modem checks

At minimum, verify the equivalents of:

```text
AT
AT+CPIN?
AT+CEREG?
AT+CSQ
AT+CMGF=1
ATD<number>;
ATA
AT+CHUP
AT+VTS=1
```

SMS does not require VoLTE, but it still requires valid carrier registration
and an accepted SMS service path. Voice may require VoLTE or a carrier-supported
2G/3G fallback. Never change an IMEI to bypass carrier policy.

USB call audio additionally requires a working PCM interface and compatible
firmware configuration. If command/control works but PCM does not, the Web UI
must report degraded audio rather than claiming calls are usable.

## Acceptance checklist

- SIM is ready and registered after reboot.
- Plain, Unicode, and long SMS work in both directions.
- Incoming/outgoing calls connect and synchronize hangup state.
- Both audio directions remain stable for at least 30 seconds.
- DTMF works.
- USB reconnect and container restart recover automatically.
