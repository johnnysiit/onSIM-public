# SIM7600 网关

[English](SIM7600.md)

SIM7600 支持取决于具体 USB 组合、Modem 固件、运营商、SIM 套餐和所在地区网络。
数据网络注册成功并不能证明短信、语音、VoLTE 或 USB PCM 一定可用。

## 硬件准入检查

1. 使用稳定电源，最好配备有源 USB Hub。
2. 通过 `dmesg` 确认 USB 设备没有反复断开。
3. 安装 `deploy/99-onsim.rules`。
4. 确认存在 `/dev/onsim-at`、`/dev/onsim-control` 和 `/dev/onsim-audio`。
5. 分别测试 SIM 就绪、网络注册、短信、通话、DTMF 和 PCM。

```sh
lsusb
dmesg --ctime | tail -100
scripts/probe-modem.sh
```

项目提供的 udev 规则覆盖已测试的 `1e0e:9011` USB 组合。不同固件可能暴露不同
接口；应检查 USB 描述符，不能猜测端口号。

## 配置

使用 SIM7600 Compose Overlay：

```sh
export ONSIM_GATEWAY_MODE=sim7600
podman compose -f compose.yaml -f compose.sim7600.yaml up -d --build
```

使用 Quadlet 时设置：

```dotenv
ONSIM_GATEWAY_MODE=sim7600
ONSIM_MODEM_MODE=auto
ONSIM_AT_PORT=/dev/onsim-at
ONSIM_CONTROL_PORT=/dev/onsim-control
ONSIM_AUDIO_PORT=/dev/onsim-audio
```

## 必做 Modem 检查

至少验证以下命令或其等价命令：

```text
AT
AT+CPIN?
AT+CEREG?
AT+CSQ
AT+CMGF=1
ATD<number>;
ATA
AT+CHUP
AT+VTS=1
```

短信不要求 VoLTE，但仍要求有效的运营商注册和可用的短信服务路径。语音可能
需要 VoLTE，或运营商支持的 2G/3G 回落。切勿通过修改 IMEI 绕过运营商策略。

USB 通话音频还要求 PCM 接口和固件配置兼容。如果命令/控制正常但 PCM 异常，
Web UI 必须报告音频降级，不能把通话标记为可用。

## 验收清单

- 重启后 SIM 就绪并成功注册。
- 普通、Unicode 和长短信均可双向收发。
- 呼入/呼出可以接通，挂断状态能同步。
- 双向音频至少稳定保持 30 秒。
- DTMF 正常。
- USB 重连和容器重启后能自动恢复。
